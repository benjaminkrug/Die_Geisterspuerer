# Cover-Bauplan NEU — CYOA-Edition "Das Haus, das flüstert"

> **Ziel dieses Dokuments:** Ein Cover, das im **Amazon-Thumbnail (150–200 px)** gewinnt.
> Große, lesbare Schrift · sofort erkennbar 2 Kinder + Hund + Haus · klar als
> Entscheidungsbuch ("DU ENTSCHEIDEST · 24 ENDEN") · gruselig genug zum Kribbeln,
> sicher genug zum Klicken.
>
> Erstellt als Spezialist für Kinder-Grusel-Cover. Jede Entscheidung ist unten begründet.

---

## 1. Warum das alte Cover nicht funktioniert (Kurz-Diagnose)

| Problem (alt) | Folge im Thumbnail | Fix (neu) |
|---|---|---|
| Titel dünn, heller Glow auf dunkelblau | verschwimmt zu grau | **fette, hohe Schrift mit dunkler Outline** |
| Kinder von hinten, dunkel auf dunkel | Figuren verschmelzen | **frontal, Gesichter, Taschenlampe beleuchtet sie** |
| Hund fast schwarz | unsichtbar | **Hund vorne, heller angeleuchtet, Augen leuchten** |
| "SPIELBUCH" klein, türkis, gesperrt | geht unter | **ersetzt durch Banner "DU ENTSCHEIDEST · 24 ENDEN"** |
| 3 Textblöcke oben gedrängt | Auge verwirrt | **klare Hierarchie, Banner = eigener Block** |
| insgesamt sehr düster | wirkt wie Erwachsenen-Thriller | **warme Akzente + mutige Gesichter = einladend** |

---

## 2. Getroffene Richtungsentscheidungen (verbindlich)

1. **Figuren:** Frontal, Gesichter sichtbar — Kinder + Hund schauen den Betrachter an
   ("Kommst du mit?"). Höchste Erkennbarkeit + Kinderbuch-Appeal.
2. **Grusel-Level:** Spannend-neugierig (nicht bedrohlich). Geheimnisvoll & einladend.
   Passt zum USP **"Kribbeln statt Albträume"**. Breiteste Zielgruppe.
3. **Trigger-Wording statt "Spielbuch":** **`DU ENTSCHEIDEST` + `24 ENDEN`** in einem
   auffälligen Banner. Begründung siehe Abschnitt 3.

---

## 3. Das Trigger-Wording — die wichtigste Textentscheidung

**Problem:** "Spielbuch" ist abstrakt. Ein 11-Jähriger scannt den Thumbnail in 0,5 s —
das Wort löst nichts aus, erklärt nichts, macht nicht neugierig.

**Lösung:** Die direkte **DU-Ansprache + eine Zahl**. Genau dieses Muster kennt die
Zielgruppe von der "1000 Gefahren"-Reihe (Ravensburger) — es ist im Kinderhirn fest
mit "SO eins, wo ICH entscheide!" verknüpft.

**Gewählte Kombination (zweistufig):**
- **Blickfang:** `DU ENTSCHEIDEST` — der Held-Claim ("ich habe die Kontrolle")
- **Beweis-Zahl:** `24 ENDEN` — macht es konkret, verspricht Wiederspielwert

> Das Wort **"SPIELBUCH" entfällt komplett** vom Front-Blickfang. Es darf höchstens
> noch klein im Untertitel für die Eltern/Amazon-Suche stehen (Abschnitt 5, Zeile F).

## 4. Bild-Komposition (von oben nach unten)

```
┌──────────────────────────────────────┐
│  DIE GEISTERSPÜRER          (Z. A)    │  ← Serientitel, fett, oben, dunkler Himmel
│ ┌──────────────────────────────────┐ │
│ │   DU ENTSCHEIDEST · 24 ENDEN     │ │  ← BANNER (Z. B), Signalfarbe, breit
│ └──────────────────────────────────┘ │
│        ┌────────────────┐             │
│        │  HILF (Fenster)│             │  ← kaltes blaues Geisterfenster = Blickfang
│        │  altes Haus    │             │
│        │  ragt auf      │             │
│        └────────────────┘             │
│      Nebel kriecht aus der Tür        │
│                                       │
│   (Mädchen) 🔦  (Junge)               │  ← FRONTAL, Gesichter, von Taschenlampe
│        \   Hund   /                   │     beleuchtet. Hund vorne mittig.
│         amber-Augen                   │
│   Das Haus, das flüstert      (Z. C)  │  ← Bandtitel
│   Benjamin Krug               (Z. D)  │  ← Autor
│   Grusel-Abenteuer ... ab 10  (Z. F)  │  ← Untertitel (für Eltern)
└──────────────────────────────────────┘
```

### Szene
- **Nachtszene, frontale Ansicht, leichter Low-Angle** (Haus wirkt größer, Kinder heldenhaft).
- **Mädchen (Nora, 12):** links, schulterlanges braunes Haar, **petrol/teal Zip-Hoodie
  (#2a8a7a — einzige kräftige Kleidungsfarbe)**, hält eine **Taschenlampe**, die ihr
  Gesicht und das des Bruders warm von unten anleuchtet. Blick: mutig, neugierig, leicht
  herausfordernd ("Kommst du mit?").
- **Junge (Theo, 10):** rechts, einen Kopf kleiner, strubbelig-lockiges dunkelblondes Haar,
  **zu große olivgrüne Bomberjacke**. Eine Hand am Rucksackriemen, leicht nervöses, aber
  mutiges Lächeln. Steht einen halben Schritt hinter Nora.
- **Hund (Schatten):** **vorne mittig zwischen den Kindern**, mittelgroßer Mischling,
  dunkles fast schwarzes Fell, **leuchtende bernsteinfarbene Augen (#d4920b)**, Ohren
  gespitzt, Nackenfell leicht aufgestellt. Vom Taschenlampenlicht angeschnitten, damit
  seine Silhouette klar lesbar ist (NICHT schwarz-auf-schwarz).
- **Das Haus:** EIN altes deutsches Altbau-Haus (3 Stockwerke + Dach, ca. 1890–1920),
  verwitterte grau-weiße Putzfassade, hohe schmale Fenster. Ragt hinter den Kindern auf,
  füllt obere Bildhälfte.
  - Erdgeschoss: dunkel.
  - 1. Stock: **ein Fenster mit warmem goldgelbem Licht** (Sicherheits-Anker, nimmt
    Härte raus).
  - 2. Stock (**DER BLICKFANG**): **ein Fenster leuchtet kalt bläulich-weiß (#c8dff5)**;
    im Kondenswasser steht **"HILF"**, wie von einem Kinderfinger geschrieben.
  - Haustür einen Spalt offen, dünner Nebel kriecht heraus.
- **CYOA-Bild-Metapher (subtil):** Das nasse Kopfsteinpflaster vor den Kindern **teilt
  sich in eine Y-Gabelung** — ein Weg zur Tür, einer biegt links in die Dunkelheit ab.
  Leise visuelle Untermalung von "DU entscheidest deinen Weg". Nicht aufdringlich.

### Stimmung & Licht (spannend-neugierig, NICHT bedrohlich)
- Primär: Vollmond oben links, kühles Silberlicht.
- **Warme Anker:** Taschenlampe auf den Gesichtern + warmes Fenster im 1. Stock +
  Bernstein-Augen → verhindern, dass es zu düster/kalt wirkt.
- Kalter Akzent: nur das Geisterfenster im 2. Stock.
- Nasses Pflaster reflektiert Mondlicht. Wenig Nebel (nur an der Tür).

### Farben
| Element | Hex | Rolle |
|---|---|---|
| Himmel | Navy → Indigo (#1a1a3e → #2d1b4e) | Grund-Düsternis |
| Geisterfenster 2. OG | #c8dff5 | kalter Blickfang |
| Warmes Fenster / Taschenlampe / Hundeaugen | #d4920b | warme Sicherheit |
| Noras Hoodie | #2a8a7a | Pop-Farbe, Wiedererkennung |

## 5. Typografie-Spezifikation (Thumbnail-optimiert)

> **Grundregel:** Lieber **wenige, große, fette** Worte als viele kleine. Jede Schrift
> bekommt eine **dunkle Outline oder Schatten**, damit sie auf dem Bild "klebt" und bei
> 150 px nicht verschwimmt. Echte Umlaute (ä ö ü Ü), niemals ae/oe/ue.

| Zeile | Text | Stil / Größe | Farbe | Effekt |
|---|---|---|---|---|
| **A — Serientitel** | `DIE GEISTERSPÜRER` | **Fette, hohe Schrift** (z.B. Cinzel/Anton/Oswald Bold), ~78 % Coverbreite, ganz oben | Silber-Weiß #e0e8f0 | **dunkle Outline #1a1a3e (4–6px)** + leichter Schatten. KEIN dünner Glow-Only mehr. |
| **B — Banner (Trigger)** | `DU ENTSCHEIDEST` (Zeile 1) · `· 24 ENDEN ·` (Zeile 2) | Breiter Balken über volle Bildbreite, direkt unter Titel. Schrift fett Sans (Montserrat Black). "24 ENDEN" am größten/auffälligsten. | Balken: Signalfarbe (Bernstein #d4920b ODER kräftiges Teal). Text: Navy #1a1a3e oder Weiß (Kontrast-Test!) | Balken leicht halbtransparent (85–90 %), 2px heller Rand. Muss als **farbiger Block** auch bei 150 px knallen. |
| **C — Bandtitel** | `Das Haus, das flüstert` | Elegante kursive Serif (Playfair Italic), ~55 % des Serientitels, unter den Figuren | Helles Türkis #7abfbf | weicher Schatten; "flüstert" löst sich nebelartig auf |
| **D — Autor** | `Benjamin Krug` | schlichte Sans (Montserrat Light), klein, unter Bandtitel | Silber #d0d8e0 | minimaler Schatten |
| **F — Untertitel (Eltern)** | `Grusel-Abenteuer zum Selbstentscheiden · ab 10 Jahren` | klein, ganz unten | gedämpftes Weiß #c0c8d0 | kein Effekt |

**Hierarchie (Lesereihenfolge im Thumbnail):**
1. `DIE GEISTERSPÜRER` (größt, fett) → 2. **Banner-Block** (Farbe sticht) →
3. **Gesichter + leuchtendes Fenster** → 4. `Das Haus, das flüstert` → 5. Autor/Untertitel.

> **Hinweis "ab 10 Jahren":** im Untertitel (für Eltern) — NICHT mehr als separates
> kleines Eck-Badge wie bisher. Reduziert Textchaos.

## 6. Zwei Wege zur Umsetzung

**Empfohlen:** Bild OHNE Text generieren (Prompt 3 unten), Typografie sauber in Canva
setzen (Spezifikation Abschnitt 5 + bestehende `Canva_Typografie_Anleitung.md`). KI-Text
hat oft Umlaut-/Buchstabenfehler. Banner + Outlines lassen sich in Canva exakt bauen.

**Schnell-Variante:** Prompt 1 (mit Text) generieren, Fehler per Follow-up korrigieren.

## 7. PROMPT 3 — Illustration OHNE Text (EMPFOHLEN, copy-paste)

```
Digital illustration, German children's book cover art, portrait orientation 1600x2560px.
Style: semi-realistic painterly digital illustration, atmospheric and detailed, like a
high-quality children's book cover. NOT photorealistic, NOT cartoon, NOT comic.
Think "Lockwood & Co" UK covers meets a warm, inviting Goosebumps color contrast.

SCENE: Night, frontal view, slight low angle so the building looms and the kids look
heroic. A girl (12) and a smaller boy (10) stand facing the viewer in front of an old
German apartment building, with a dog between them. Their look says "Are you coming?"
Mysterious and exciting, NOT threatening.

THE CHILDREN (lower third, FACES VISIBLE, lit warmly from below by a flashlight):
- Girl (left): shoulder-length brown hair, DARK TEAL zip hoodie (#2a8a7a). Holds a
  flashlight that warmly lights both kids' faces from below. Brave, curious, slightly
  daring expression.
- Boy (right): a head shorter, messy curly dark-blond hair, oversized OLIVE-GREEN bomber
  jacket. One hand on his backpack strap, nervous-but-brave little smile. Half a step

- Dog (center front, between them): medium-sized mixed breed, almost black fur, GLOWING
  AMBER EYES (#d4920b), ears forward, hackles slightly raised. Catch the dog with rim
  light / flashlight glow so its silhouette is CLEARLY readable, never black-on-black.

THE BUILDING (upper half, behind the kids): ONE tall old German Altbau, 3 stories,
weathered grey-white plaster, tall narrow windows. Looms slightly.
- Ground floor: dark.
- First floor: ONE window with WARM golden glow (#d4920b) — a safe anchor.
- Second floor (FOCAL POINT): ONE window glows COLD BLUE-WHITE (#c8dff5). In the
  condensation on that window the word HILF is barely visible, written by a child's
  finger. This is the eye-catcher.
- Front door slightly ajar, thin fog seeping out from underneath.

ATMOSPHERE & CYOA CUE:
- Wet cobblestones reflecting moonlight. The cobblestone path in front of the children
  SPLITS INTO A Y-FORK — one path to the door, one curving away into darkness to the
  left. Subtle metaphor for "you choose your path." Keep it natural.
- Cold silver moonlight from upper left, pale full moon partly behind clouds.
- Color palette: deep navy (#1a1a3e), indigo (#2d1b4e), with WARM amber accents
  (flashlight, first-floor window, dog eyes) and the single teal hoodie. NOT uniformly
  dark — warm light keeps it inviting, not scary.

COMPOSITION FOR TEXT (leave space):
- Upper ~22%: dark sky / rooftops. MUST BE DARK AND RELATIVELY EMPTY — series title goes
  here later.
- A clear horizontal band under the title area — KEEP IT SIMPLE — a banner goes here.
- Lower ~15%: cobblestones / feet, dark — band title and author go here.
- The cold blue window sits upper-middle as the eye-catcher.

CRITICAL RULES:
- ABSOLUTELY NO TEXT anywhere except the faint word HILF in the window condensation.
- NO other people, no visible ghost, no monster, no skull, no blood.
- The image must read clearly when scaled down to 150px width: 2 kids' faces + dog +
  glowing window must all be instantly recognizable.
- Keep 15% safe margin from all edges (Amazon KDP crops there).
```

## 9. Korrektur-Prompts (Follow-up)

**Text falsch:**
```
Korrigiere NUR den Text, ändere nichts am Bild. Echte Umlaute (Ü, ü):
- Titel: "DIE GEISTERSPÜRER"
- Banner Zeile 1: "DU ENTSCHEIDEST"   Zeile 2: "· 24 ENDEN ·"
- Bandtitel: "Das Haus, das flüstert"
- Autor: "Benjamin Krug"
- Unten: "Grusel-Abenteuer zum Selbstentscheiden · ab 10 Jahren"
Buchstabiere jedes Wort vor dem Schreiben.
```

**Zu düster/gruselig:**
```
Zu düster für Kinder ab 10. Mehr warmes Taschenlampenlicht auf den Gesichtern,
helleres warmes Fenster im 1. Stock, etwas weniger Nebel, Kinder etwas heller.
Stimmung: "mysteriös & spannend", nicht "bedrohlich".
```

**Zu hell/harmlos:**
```
Zu freundlich. Dunklerer Nachthimmel, mehr Kontrast beim kalten blauen Fenster,
tiefere Schatten am Boden. Ziel: Neugier & Kribbeln, keine Angst. Gesichter aber
weiterhin klar warm beleuchtet.
```

## 10. THUMBNAIL-TEST (PFLICHT vor Upload)

Cover auf **150 × 240 px** verkleinern und abhaken:

- [ ] `DIE GEISTERSPÜRER` klar lesbar (nicht verwaschen)?
- [ ] **Banner als farbiger Block sofort sichtbar?** ("24 ENDEN" erkennbar?)
- [ ] **2 Kindergesichter + Hund** sofort als solche erkennbar?
- [ ] Kaltes blaues Fenster als Lichtpunkt sichtbar?
- [ ] Bernstein-Augen des Hundes als warme Punkte sichtbar?
- [ ] Gesamteindruck in 0,5 s: **"Grusel-Entscheidungs-Abenteuer mit 2 Kindern + Hund vor Spukhaus, ab 10"**?
- [ ] Wirkt es **einladend-spannend**, nicht **düster-bedrohlich**?

> Wenn auch nur ein Punkt fehlt → zurück zu Prompt 3 oder Typografie nachschärfen.
> Der Thumbnail-Test ist der einzige Test, der über Klick / kein Klick entscheidet.
