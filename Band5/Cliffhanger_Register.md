## Cliffhanger-Typen (zur Muster-Kontrolle)
- **BILD** = visueller Schock (ein Ding, ein Anblick, eine Erscheinung)
- **WORT/HINWEIS** = ein Wort/Fund/Schrift, dessen Bedeutung offen bleibt (Mitraten)
- **DIALOG** = eine Aussage/Bitte/Frage/Drohung einer Figur
- **GEDANKE** = eine Erkenntnis/ein Verdacht/eine innere Wende der Kinder
- **AKTION** = etwas passiert physisch (Riss, Griff, Schatten reißt sich los)
- **STIMME** = eine körperlose Stimme/ein Ruf aus dem Off

## Muster-Wächter (Vorab-Kontrolle der geplanten Reihenfolge)

**★ Behobene Häufung aus der Phase-2-Prüfung (K11–14 waren alle AKTION-nah):** bewusst ausdifferenziert →
- **K11 = GEDANKE** (Noras innere Beinah-Wende, das Zögern an der Spiegel-Vision — der Riss ist nur die Folge, nicht der Kern)
- **K12 = DIALOG** (Theos Zeile trägt den Cliffhanger, nicht die Aktion)
- **K13 = AKTION** (das Echo wird gesogen, physische Dringlichkeit)
- **K14 = GEDANKE** (die Hoffnung, die sich sofort wieder schließt)
→ Reihenfolge K10–K16: DIALOG · GEDANKE · DIALOG · AKTION · GEDANKE · AKTION · BILD. **Keine zwei gleichen in Folge.**

**Alle Übergänge geprüft (kein Typ 2× hintereinander):**
1 BILD → 2 STIMME → 3 AKTION → 4 DIALOG → 5 WORT → 6 AKTION → 7 STIMME → 8 BILD → 9 STIMME → 10 DIALOG → 11 GEDANKE → 12 DIALOG → 13 AKTION → 14 GEDANKE → 15 AKTION → 16 BILD → 17 GEDANKE. **✓ durchgehend verschieden.**
- Wachpunkt K7→K8: K7 primär **STIMME** (Gravens offene Ankündigung = der Punch); das Echo-Kind-Einfrieren spielt MITTEN im Kapitel, NICHT als Schlussbild → K8 (BILD, "da ist niemand") bleibt klar getrennt. Beim Schreiben so bauen.
- Wachpunkt K7/K9 beide STIMME (nicht adjazent, K8 dazwischen): K7 = Ankündigung (freudig), K9 = Ultimatum (müde, ohne Höflichkeit) → tonal klar verschieden, kein wortgleicher Ruf.

**Klammer-Motiv (bewusst wiederkehrend, KEIN Fehler):** die Karte / der GRAVEN-Kreis (Serien-Motiv wie B3/B4): K1 (glüht schwach) → K9 (glüht hell, Ultimatum) → K18 (alle 12 durch, erloschen). Jedes Mal anders (Erwachen → Höhepunkt → Abschluss). Kein wortgleicher Cliffhanger.

**STIMME-Cluster im Auge behalten:** 3× STIMME (2/7/9) — für einen Geist, der v. a. durch seine *Stimme* präsent ist (bevor er in K10 erscheint), ist das gewollt und figurenlogisch. ABER: tonal variieren (K2 lockend, K7 triumphierend-freudig, K9 müde-drohend), damit es nicht "schon wieder eine Off-Stimme" wird.

**Regel:** Nach jedem fertigen Kapitel Cliffhanger-Kurzform + Typ hier bestätigen. Nie 2× wortgleich, nie 2× denselben Typ direkt hintereinander.
