## C. Regeln für die Pflege

1. Neuer Hinweis im Text → sofort als Zeile in Tabelle A/B eintragen.
2. Payoff geschrieben → Kapitel-Nummer + Status "erledigt" eintragen.
3. Faires Spiel: Ein Payoff in Kap N darf NUR Hinweise nutzen, die mit "gesät ≤ N" stehen. Sonst = Hut-Trick → Hinweis früher einbauen.
4. Vor Abschluss Band 4: keine Zeile darf "geplant"/"offen" sein (außer bewusst Band-5: E9, E10, #18, #19).
5. Besonders wachsam bei den GEERBTEN Fäden (Tabelle A) — ein vergessener Serien-Faden fällt in einer Twist-Serie doppelt auf.
