## Cliffhanger-Typen (zur Muster-Kontrolle)
- **BILD** = visueller Schock (ein Ding, ein Anblick, eine Erscheinung)
- **WORT/HINWEIS** = ein Wort/Fund, dessen Bedeutung offen bleibt (Mitraten)
- **DIALOG** = eine Aussage/Bitte/Frage/Drohung einer Figur
- **GEDANKE** = eine Erkenntnis/ein Verdacht der Kinder
- **AKTION** = etwas passiert physisch (Raum schließt sich, Griff, Einbruch)
- **STIMME** = eine körperlose Stimme/ein Ruf aus dem Off

## Muster-Wächter (Vorab-Kontrolle der geplanten Reihenfolge)

**Typ-Verteilung geplant:** WORT/HINWEIS (1,16) · BILD (2,5,15) · DIALOG (3,7,9,13,14) · STIMME (4,8,10) · AKTION (6,9,12) · GEDANKE (11)

**Geprüft — keine zwei GLEICHEN Typen hintereinander:**
- K3→K4: DIALOG(Schrift) → STIMME ✓ (verwandt, aber Schrift vs. gesprochene Stimme = klar verschieden)
- K7→K8: DIALOG → AKTION+STIMME ✓
- K9→K10: DIALOG+AKTION → STIMME ✓
- K13→K14: DIALOG → DIALOG ⚠️ **ACHTUNG:** Zwei DIALOG-Cliffhanger in Folge (Theo „ZEIGEN" / Faber „Ich weiß es noch"). Beim Schreiben differenzieren: K13 ist eine ENTSCHEIDUNG/ein Plan (vorwärts), K14 eine WENDE/ein Durchbruch (Faber öffnet die Hand). Inhaltlich verschieden genug — aber K14 stärker über das BILD (die offene Hand, das Medaillon darauf) tragen als über den Satz, damit es sich nicht wie „noch ein Dialog-Cliffhanger" liest. → K14 Typ beim Schreiben eher zu BILD+DIALOG kippen.

**Klammer-Motiv (bewusst wiederkehrend, KEIN Fehler):** Rahmen-Bild B4 = die Karte, die sich verändert (K1 Grundriss → K15 Markierung streicht sich → K16 fremde Schrift). Das ist ein SERIEN-Motiv (wie in B3), bewusst dreimal — aber jedes Mal anders (Grundriss / Durchstreichen / Satz-Vollendung). Kein wortgleicher Cliffhanger.

**Noch freie/starke Typen für Variation:** GEDANKE nur 1× (K11) — falls beim Schreiben ein Cliffhanger schwächelt, ist ein Erkenntnis-Cliffhanger (Kinder begreifen etwas Kaltes) noch unterrepräsentiert und stark.

**Regel:** Nach jedem fertigen Kapitel Cliffhanger-Kurzform + Typ hier bestätigen. Nie 2× wortgleich, nie 2× denselben Typ direkt hintereinander (K13/K14 im Auge behalten).
