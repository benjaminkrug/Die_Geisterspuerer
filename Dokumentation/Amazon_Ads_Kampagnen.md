## Anleitung: So legst du die Kampagnen an

### Schritt für Schritt in Amazon Advertising:

1. **Geh zu** advertising.amazon.de → Kampagne erstellen
2. **Wähle** "Sponsored Products"
3. **Kampagnenname** eingeben (z.B. `GS_Band1_TB_Grusel_Broad`)
4. **Tagesbudget** eingeben (siehe oben pro Kampagne)
5. **Gebotsstrategie:** "Dynamische Gebote — nur senken"
6. **Anzeigengruppe erstellen** → Name = gleich wie Kampagne
7. **Produkt wählen:** Dein Taschenbuch Band 1 auswählen
8. **Targeting:** "Manuelles Targeting" → "Keyword-Targeting"
9. **Keywords eingeben:**
   - Kopiere die Keywords aus der jeweiligen Kampagne oben
   - Klicke auf "Liste eingeben"
   - Füge alle Keywords ein
   - **Match-Type auf "Broad" stellen** (für ALLE Keywords)
   - **Gebot:** das Standardgebot von oben übernehmen
10. **Negatives Targeting:**
    - Klicke auf "Negatives Keyword-Targeting"
    - Kopiere die negativen Keywords rein
    - **Match-Type auf "Exact" stellen**
11. **Kampagne starten**

### Nach 7 Tagen — Erste Optimierung:

- Keywords mit Klicks aber 0 Sales → Gebot auf 0,10 € senken
- Keywords mit vielen Impressionen aber 0 Klicks → Gebot um 0,03 € erhöhen
- Keywords mit Sales → in neue Kampagne mit **Exact Match** und Gebot 0,25-0,35 €
- Keywords mit hohem ACoS (über 40%) → pausieren

### Nach 14 Tagen — Zweite Optimierung:

- "Winner" Keywords (Sales + ACoS unter 30%) → Gebot erhöhen auf 0,30-0,40 €
- "Loser" Keywords (viele Klicks, 0 Sales nach 14 Tagen) → pausieren
- Suchbegriff-Bericht prüfen → neue Keywords entdecken → hinzufügen
